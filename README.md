# OIBSIP - Oasis Infobyte Java Development Internship

This repository contains the projects completed as part of the **Oasis Infobyte Java Development Internship (OIBSIP)**.

## Projects

### 1. ATM Management System

A console-based Java application that simulates basic ATM operations.

#### Features

* User Login
* Balance Enquiry
* Cash Deposit
* Cash Withdrawal
* Fund Transfer
* Transaction History
* Change PIN

#### Technologies Used

* Java
* JDBC
* PostgreSQL
* Maven
* Object-Oriented Programming (OOP)

---

### 2. Library Management System

A Spring Boot REST API for managing library operations.

#### Features

* Library Management
* User Management
* Book Management
* Address Management
* Borrow and Return Books
* Exception Handling
* Layered Architecture (Controller, Service, Repository)

#### Technologies Used

* Java
* Spring Boot
* Spring Data JPA
* Hibernate
* PostgreSQL
* Maven
* Lombok
* REST API
* Postman

## How to Run

### ATM Management System

1. Clone the repository.
2. Open the `Atm_management` project in your IDE.
3. Configure the PostgreSQL database.
4. Run the application.

### Library Management System

1. Open the `Library-Management_System` project.
2. Update the database credentials in `application.properties`.
3. Run the Spring Boot application.
4. Test the REST APIs using Postman.
